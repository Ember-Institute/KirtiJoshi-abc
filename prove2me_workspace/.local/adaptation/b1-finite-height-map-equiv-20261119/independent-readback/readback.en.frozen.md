Let $T$ and $T'$ be fields of characteristic zero and finite dimension over $\mathbb{Q}$, and let $e\colon T\to T'$ be any field isomorphism. For $F=T$ or $F=T'$, let $\mathcal{V}_F$ be the set of real-valued absolute values attached to the nonzero prime ideals $\mathfrak{p}$ of the ring of integers $\mathcal{O}_F$. The absolute value $v$ attached to $\mathfrak{p}$ has $v(0)=0$ and satisfies $v(a/b)=\bigl(\#(\mathcal{O}_F/\mathfrak{p})\bigr)^{-\operatorname{ord}_{\mathfrak{p}}(a)+\operatorname{ord}_{\mathfrak{p}}(b)}$ for nonzero $a,b\in\mathcal{O}_F$, where $\#(\mathcal{O}_F/\mathfrak{p})$ is the number of elements in the quotient and $\operatorname{ord}_{\mathfrak{p}}(c)$ is the multiplicity of $\mathfrak{p}$ in the prime ideal factorization of the nonzero principal ideal $(c)$. Set $\log^+(0)=0$ and $\log^+(r)=\max\{0,\ln|r|\}$ for every nonzero real $r$. Each $\sum^{\mathrm{fin}}$ adds the nonzero summands when their index set is finite, with value zero if that set is empty. Its value is also zero if that set is infinite. For every $y\in T$ the following equality of real numbers holds, with both sides equal to zero when $y=0$.

$$
\sum_{v'\in\mathcal{V}_{T'}}^{\mathrm{fin}} \log^+\bigl(v'(e(y))\bigr)
=
\sum_{v\in\mathcal{V}_T}^{\mathrm{fin}} \log^+\bigl(v(y)\bigr).
$$
