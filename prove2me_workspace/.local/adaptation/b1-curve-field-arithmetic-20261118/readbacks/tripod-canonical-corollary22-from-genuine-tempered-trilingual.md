# Canonical Corollary 2.2 on the genuine tempered theory

## English

The theorem takes a Legendre curve provider `P`. It uses `Pi1 := genuineEtalePi1Theory canLift27` and `T := genuineTemperedPi1Theory canLift27` for the same model orbicurves. `Pi1` supplies core finiteness. The pair `Pi1` and `T` supplies `modelTG Pi1 T` and `anabelianExistence Pi1 T`. [Concrete theory](../../../../Solutions/Source_ReferenceIutGenuineTempered.lean#L39) · [Theorem](../../../../Solutions/Source_TripodCanonicalCorollary22FromGenuineTempered.lean#L17)

For each compactly bounded set `K` and degree bound `d`, the theorem builds `CI` from `P`, the proved cyclic bound, and core finiteness. It uses the existing Northcott, Legendre height, and two-adic bounds. The premise `h312` gives `X.qPilot.lhs ≤ X.rhsData.rhs` for each `X` satisfying `IsSourceP7Variant CI (anabelianExistence Pi1 T) X`. This predicate identifies the bundle with the construction for a point and prime satisfying P7. The pinned source applies the inequality to the P7 witness under its more general hypothesis on `concreteVariantData`. [Premise](../../../../Solutions/Source_TripodCanonicalCorollary22FromGenuineTempered.lean#L19) · [P7 predicate](../../../../Solutions/Source_TripodP7.lean#L27) · [Pinned source](https://github.com/lana-agents/iut/blob/07cb1da58f6d428a670dbb5dd6093d428bcbcdd8/Iut/Tripod/Main.lean#L129)

`pointThetaDataExistence_from_canLift27_genuineTempered` supplies a witness on that exact family. The canonical Corollary 2.2 proof uses the witness, `h312`, and the proved prime bounds. For each `K` and positive `d`, it gives a finite exception set, a height threshold, and a uniform constant. The bounds apply to points in `K` outside the exception set with degree at most `d` and height at or above the threshold. The estimate uses `auxiliaryHeight`, the finite height of the Legendre `j`-invariant divided by the point's degree. [P7 witness](../../../../Solutions/Source_TripodP7FromGenuineTempered.lean#L15) · [Corollary 2.2 proof](../../../../Solutions/Source_TripodCanonicalCorollary22FromGenuineTempered.lean#L36) · [Canonical conclusion](../../../../Definitions/Def_TripodCanonicalHighHeightInputs.lean#L54)

The result supplies `hC2` in `highHeightEstimate_of_canonical_children`. The same provider `P` supplies the comparison with `htCan`. The large-height error estimate completes the input to this proof. `statementII_of_children` then uses its output and bounded-degree finiteness to obtain `StatementII`. ## 简体中文

定理取 Legendre 曲线提供器 `P`，在同一批模型轨形曲线上使用 `Pi1 := genuineEtalePi1Theory canLift27` 和 `T := genuineTemperedPi1Theory canLift27`。`Pi1` 给出核心有限性。`Pi1` 与 `T` 共同给出 `modelTG Pi1 T` 和 `anabelianExistence Pi1 T`。 [具体理论](../../../../Solutions/Source_ReferenceIutGenuineTempered.lean#L39) · [定理](../../../../Solutions/Source_TripodCanonicalCorollary22FromGenuineTempered.lean#L17)

对每个紧有界集 `K` 和次数界 `d`，定理用 `P`、已证明的循环子群界和核心有限性构造 `CI`，并使用已有的 Northcott、Legendre 高度和 2 进界。前提 `h312` 要求每个满足 `IsSourceP7Variant CI (anabelianExistence Pi1 T) X` 的 `X` 都满足 `X.qPilot.lhs ≤ X.rhsData.rhs`。该谓词将数据包与满足 P7 的点和素数所构造的数据包等同。固定版本的来源在对 `concreteVariantData` 的更一般前提下，将不等式应用于 P7 见证。 [前提](../../../../Solutions/Source_TripodCanonicalCorollary22FromGenuineTempered.lean#L19) · [P7 谓词](../../../../Solutions/Source_TripodP7.lean#L27) · [固定版本的来源](https://github.com/lana-agents/iut/blob/07cb1da58f6d428a670dbb5dd6093d428bcbcdd8/Iut/Tripod/Main.lean#L129)

`pointThetaDataExistence_from_canLift27_genuineTempered` 为同一族提供见证。规范化推论 2.2 的证明使用该见证、`h312` 和已证明的素数界。对每个 `K` 和正整数 `d`，它给出有限例外集、高度阈值及一致常数。在 `K` 中且在例外集之外，次数至多为 `d` 且高度达到阈值的点满足 `CanonicalCorollary22HighHeightEstimate` 中的估计。这个估计使用 `auxiliaryHeight`，即 Legendre 曲线的 `j` 不变量的有限部分高度除以该点的次数。 [P7 见证](../../../../Solutions/Source_TripodP7FromGenuineTempered.lean#L15) · [推论 2.2 的证明](../../../../Solutions/Source_TripodCanonicalCorollary22FromGenuineTempered.lean#L36) · [规范化结论](../../../../Definitions/Def_TripodCanonicalHighHeightInputs.lean#L54)

所得结论可作为 `highHeightEstimate_of_canonical_children` 的 `hC2`。同一个 `P` 给出与 `htCan` 的比较，已有的大高度误差估计补齐输入。`statementII_of_children` 将得到的大高度估计与有界次数下的有限性结合，推出 `StatementII`。 [提供器高度比较](../../../../Solutions/Source_TripodProviderLegendreComparison.lean#L20) · [大高度组装](../../../../Definitions/Def_TripodCanonicalHighHeightComposition.lean#L22) · [Statement II 组装](../../../../Definitions/Def_TripodStatementIIComposition.lean#L21)

## 日本語

定理は Legendre 曲線の供給者 `P` を取る。同じモデル軌道曲線に `Pi1 := genuineEtalePi1Theory canLift27` と `T := genuineTemperedPi1Theory canLift27` を用いる。`Pi1` はコアの有限性を与える。`Pi1` と `T` から `modelTG Pi1 T` と `anabelianExistence Pi1 T` を得る。 [具体的な理論](../../../../Solutions/Source_ReferenceIutGenuineTempered.lean#L39) · [定理](../../../../Solutions/Source_TripodCanonicalCorollary22FromGenuineTempered.lean#L17)

各コンパクト有界集合 `K` と次数上界 `d` に対し、`P`、証明済みの巡回部分群の上界、コアの有限性から `CI` を構成する。ここでは既存の Northcott の有限性、Legendre 高さの評価、2 進の上界を用いる。仮定 `h312` は `IsSourceP7Variant CI (anabelianExistence Pi1 T) X` を満たす各 `X` に対して `X.qPilot.lhs ≤ X.rhsData.rhs` を要求する。この述語は、データが P7 を満たす点と素数から構成したものに等しいことを表す。固定版の原典は `concreteVariantData` に関するより一般の仮定のもとで、この不等式を P7 の証拠に適用する。 [仮定](../../../../Solutions/Source_TripodCanonicalCorollary22FromGenuineTempered.lean#L19) · [P7 の述語](../../../../Solutions/Source_TripodP7.lean#L27) · [固定版の原典](https://github.com/lana-agents/iut/blob/07cb1da58f6d428a670dbb5dd6093d428bcbcdd8/Iut/Tripod/Main.lean#L129)

`pointThetaDataExistence_from_canLift27_genuineTempered` が同じ族の証拠を与える。標準化した系 2.2 の証明は、その証拠、`h312`、証明済みの素数評価を使う。各 `K` および正整数 `d` に対し、有限例外集合、高さの閾値、一様定数を得る。`K` の中で例外集合に属さず、次数が `d` 以下かつ高さが閾値以上の点には、`CanonicalCorollary22HighHeightEstimate` の評価が成り立つ。この評価で使う `auxiliaryHeight` は、Legendre 曲線の `j` 不変量の高さの有限部分を点の次数で割った値である。 [P7 の証拠](../../../../Solutions/Source_TripodP7FromGenuineTempered.lean#L15) · [系 2.2 の証明](../../../../Solutions/Source_TripodCanonicalCorollary22FromGenuineTempered.lean#L36) · [標準化した結論](../../../../Definitions/Def_TripodCanonicalHighHeightInputs.lean#L54)

得られた結論は `highHeightEstimate_of_canonical_children` の `hC2` に渡せる。同じ供給者 `P` が `htCan` との比較を与え、既存の大きな高さでの誤差評価を合わせて入力をそろえる。`statementII_of_children` は得られた高さ評価と有界次数での有限性から `StatementII` を導く。 [供給者による高さ比較](../../../../Solutions/Source_TripodProviderLegendreComparison.lean#L20) · [大きな高さでの合成](../../../../Definitions/Def_TripodCanonicalHighHeightComposition.lean#L22) · [Statement II の合成](../../../../Definitions/Def_TripodStatementIIComposition.lean#L21)
