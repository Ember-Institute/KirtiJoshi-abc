## Actual export and comparisons

The inventory contains 151 original compiler declarations; 83 are mandatory selected declarations. All 151 are exported. Each record contains the compiler's `ConstantInfo.type`, any available value, structured `Name` components, ordered `levelParams`, nested binder information, original module/source hash, complete axiom closure, type/value axiom closures, and source proposition status. Inductive/constructor/recursor metadata and every recursor rule RHS are retained. Readable telescope displays are diagnostic only; they are never parsed back into expressions.

The codec erases `Expr.mdata`, preserves every other supported kernel Expr constructor, and rejects free variables or metavariables. Structural Names preserve numeric name components. All source names in this inventory have the displayed string components used by the generated config; the exporter checks actual constant lookup and owner rather than accepting graph text as an Expr.

The platform audit requires all 83 mandatory targets. Every original/target pair that exists, including constructor and field accessor declarations, must have the same ConstantInfo kind, same universe count, and kernel-convertible actual types after explicit name relocation and universe alpha-renaming. It compares full nested BinderInfo inventories and binder positions separately because kernel conversion ignores BinderInfo. Source and target expressions are checked by `Kernel.check` before `Kernel.isDefEq`. No metavariables or elaborator unification are used to make a comparison pass.

For non-proposition declarations with values, the relocated original value must inhabit the original type and be kernel-convertible to the target value. This covers predicate definitions, `Procession.standard`, data projections, class instances, `pointMap`, and matcher/deriving definitions. Inductives and constructors additionally compare computation metadata; recursors additionally compare every kernel rule RHS. Structure field names, order, and accessor identities are checked. Instance registry membership must equal each `expectedIsInstance` flag from the accepted original compiler graph `ci-012771-ee109b3e`; the config is bound to that inventory hash. Preserved original attribute commands provide separate source evidence. Consequently changing only a type signature while changing a computational definition is insufficient.

Proof declaration bodies are not compared byte-for-byte. They must retain exact kernel types and use only `propext`, `Classical.choice`, and `Quot.sound` in their transitive axiom closures. Data definitions with proof fields still undergo value conversion: kernel proof irrelevance can ignore those fields' proof internals, while the structure/constructor types preserve their obligations. `sorryAx` and new axioms fail the audit. All declarations actually owned by the five artifacts, including target-only generated auxiliaries, receive type/value/recursor-dependency owner checks and full axiom audits.

The result reports absent unselected original declarations and target-only compiler declarations. These are source-generation review inputs, not permission to omit any of the selected 83. A target-only declaration has an axiom audit but no old-version exact-type claim. Main-agent acceptance must establish that it comes from the retained original source commands before publication.
