## 六、负面证据（不计为开放义务的完成）

以下条目说明哪些路线已经被排除，以及排除范围。它们不能被改写成论文反例或最终
定理的负面证明。

### N1：q-root 不能直接充当旧 theta base

S1.243/S1.321 的 `ThetaLogSignAudit.lean` 证明 actual contracting q-root 的 norm 小于
1，而旧 theta/period/normalization 与 volume transfer 要求非负 `logVolume`。因此排除
“q-root norm = theta base norm”；不排除另一个 theta lift、different untilt 或
negative-log cost。

### N2：signed Haar log-volume 不能直接填入 `VolumeTransfer`

actual ordinary-log hull 在正长度时的 signed Haar log-volume 严格为负。S1.321 排除
直接 transfer；S1.322/S1.406 保留 `-log(volume)` actual cost 路线。该路线仍缺 paper
`thetaVolume` identity。

### N3：字面 Corollary qLogTerm 存在符号冲突

S1.305 证明 actual selected contracting q-root 下，字面右端
`-∑ log |q_w^(1/(2ℓ))|` 为正而字面左端非正。用户决定按笔误暂处理（S1.332）；这不
冻结最终 target，也不允许静默反号或取 reciprocal。

### N4：ambient unit/Kummer carrier 不能改名为 H¹ₑ/BK

S1.403、S1.447–451 证明 actual continuous H¹、unit subspace、saturated Kummer carrier
和 normalized ordinary-log witness 的局部事实；S1.451 还排除当前 q-root class 属于
normalized principal-unit class 的 ℚₚ 单生成空间。它们不能被改名为 H¹ₑ/BK，也不排除
真实 period/holomorphoid producer 提供另一种比较。

### N5：固定 completion orbit 不能替代跨 holomorphoid collation

actual factor automorphism、closure、hull 和 Haar monotonicity 只在固定 completion tensor
内成立。它们不能替代不同 untilt、arithmeticoid、moduli point 之间的 Ind1–Ind3 和
global collation。

### N6：canonical finite carrier 不能自动成为 `V_p^oss` 或 `L'`

S1.489–503 的 coefficient-weighted accounting 保留 representative defect、omitted mass
和 global degree 因子。finite equivalence、degree-one witness 或 selected support 不能
自动改名为论文处集、代表或无缺陷 paper sum。

### N7：参考工程没有当前所需的联合真实 producer

`refer/iut` 的 `AnabelianExistence` 是条件接口，model existence 只适用于 `modelAG/modelTG`。
参考工程没有任意真实 `AG/TG`、holomorphoid marking、H¹ₑ/BK、Fréchet `B`/ρ-norm 和
paper collation 的联合 proof。不能通过移植 `thetaData`、扩大 `PerfectoidBridgeLaws` 或
调用 `Prologue/Obligations` 宣布生产者存在。
