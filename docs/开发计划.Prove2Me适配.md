## 3. 固定最终 abc 目标及其语义

- [x] 保留现有平台标识 `abc.variants.lt_constant_mul`，不因参考文件外层命名空间为 `ABC` 而另建重复根目标。
- [x] 形式陈述明确量化正实数 `ε`、一个实常数 `K`，以及满足正性、集合互素和 `a + b = c` 的自然数三元组。
- [x] 保留目标的严格不等式 `(c : ℝ) < K * (radical (a * b * c) : ℝ) ^ (1 + ε)`；实数幂、根基和强制转换已经明确。
- [x] 目标使用 Mathlib 的 `UniqueFactorizationMonoid.radical`，已验证它在自然数上等于来源中的不同素因子乘积。
- [ ] 在根目标的最终适配证明中逐项处理参考工程与平台目标的差异：自然数或整数、`≤` 或 `<`、`Nat.Coprime a b` 或集合上的 `Pairwise`、显式或推得的 `c > 0`。
- [ ] 针对 `Set.Pairwise` 只约束不同数值的语义证明所需转换；尤其处理 `a = b` 的情形，不以“互素三元组”文字替代此项证明。
- [ ] 如从非严格上界转为严格上界，使用合法的统一常数增大，并证明根基的实数幂为正；不得直接把 `≤` 改写成 `<`。
- [ ] 保持 `K` 在三元组量化之前选择，只依赖 `ε`；不得让 `K` 隐含依赖 `a,b,c`。
- [ ] 核对不显式要求 `K > 0` 的现有目标与所用参考版本的关系；需要时由合法三元组推出常数正性。
- [ ] 不向最终根目标增加 `h312`、producer、height theory、anabelian theory 或其他未消除数学输入。

- [ ] 草稿／开放陈述：以平台要求的 `:= by sorry` 标记尚待证明的节点；编译成功只说明陈述可 elaboration，不表示数学结论已证明。
