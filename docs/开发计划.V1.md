## 1. 目标

本版本把工程分成四个阶段：

```text
Prologue
  └─ 从 mathlib、JoshiTeich 论文和 IUT 参考工程建立有来源的载体与接口
       ↓
Act1Scene1
  └─ 接收 Prologue 的显式接口，无需调用其 sorry 构造子，完整推出 Corollary 3.12
       ↓
Act1Scene2
  └─ 从 Corollary 3.12 完整完成主界、Vojta、strong abc 和 classical abc 链
       ↓
Act2
  └─ 在 Act1 全部闭合后，消除 Prologue 中积压的证明义务
```

Act1 的公开交付物是两个没有 `sorry`、没有自定义 `axiom`、没有隐藏证明的证明层：

- `Act1Scene1` 说明明确的中间接口足以推出 Joshi 版本的 Corollary 3.12；
- `Act1Scene2` 说明 3.12 之后的数论链如何推出 `abc`。

Prologue 可以有未完成的构造证明，但它只能以有来源的、非退化的接口形式存在。
任何证明缺口都必须可定位、可计数、可由 Act2 单独消除。不能把一个空洞命题改名为
另一个空洞命题，也不能把 Corollary 3.12 本身包装成前置接口。

## 2. 阶段边界

### 2.1 Prologue

Prologue 覆盖从 mathlib 和参考材料到 `AdelicThetaLink` 的基础设施：数域、素位、
赋值、different、conductor、height、untilt、Frobenius、Tate 参数、theta 数据、
packet、hull、log-volume 和 adelic theta-link 的载体与命题接口。

Prologue 允许在明确登记的构造定理中使用 `sorry`。这些定理只是待完成的证明义务，
不能被 Act1Scene1 或 Act1Scene2 调用。

### 2.2 Act1Scene1

Scene1 只导入 Prologue 的载体和无证明缺口的接口定义。它通过显式参数接收
`AdelicThetaLink`、theta lift、packet/hull 和 volume transfer 等输入，完整证明
Corollary 3.12。

`#print axioms` 对 Scene1 的公共定理不得出现 `sorryAx`。Prologue 中存在的
`sorry` 不得通过全局实例、全局常量或隐藏构造子进入 Scene1。

### 2.3 Act1Scene2

Scene2 只导入 Scene1 的定理和明确的后续桥接接口，完整证明：

```text
Corollary 3.12
  → theta log-volume 上界
  → different/conductor 与主界
  → Vojta 型不等式
  → strong abc
  → classical abc
```

different、conductor 和 height 属于 3.12 之后的主界链，不得为了填充
Corollary 3.12 而提前吞进 `AdelicThetaLink`。

如果某个桥接结果尚未证明，必须作为显式命名参数保留；不得用 Prologue 的 `sorry`
定理偷偷提供它。Act1 的最终闭合标准要求导出的 `abc` 定理本身没有这类未说明的
参数。

### 2.4 Act2

Act2 在 Act1 全部闭合之前不得开始实现。Act2 负责逐项替换 Prologue 中的 `sorry`
构造证明，并在最后把已证明的构造与 Act1 的无缺口证明层组合起来。

Act2 不得反向成为 Prologue 或 Act1 的依赖。依赖方向固定为：

```text
Prologue → Act1Scene1 → Act1Scene2
Prologue → Act2
Act1Scene1 → Act2
Act1Scene2 → Act2
```

## 3. 总体信任规则

- 不声明项目自定义 Lean `axiom`、`admit` 或隐藏的 `opaque` 证明。
- `sorry` 只允许出现在 Prologue 的命名证明义务中。
- 每个 `sorry` 必须有唯一 `source-id`、来源位置、陈述忠实度、依赖项和 Act2 归属。
- 需要下游计算的数据必须位于 `Type` 载体中；性质放在 `Prop` 中。
- 所有公共定理使用显式参数，不使用隐式全局数学结论。
- `#print axioms` 只审计证明项依赖；接口假设必须通过定理签名和来源登记审计。
- 直接复制 IUT 代码不等于接受其数学结论。复制文件必须在冻结环境下编译，检查
  `sorry`/`axiom`/外部依赖，并登记版权、许可证、原提交和改写范围。

## 4. Act1 闭合门槛

只有以下条件全部满足，才允许创建或实现 Act2：

- [ ] Prologue 的所有公共载体和接口均有论文、IUT 或 mathlib 来源；
- [ ] Prologue 的每个接口都有非退化满足模型和违反模型，或有明确的模型义务登记；
- [ ] Scene1 的 3.12 推导不导入或调用 Prologue 的 `sorry` 构造子；
- [ ] Scene1 的公共定理没有 `sorryAx`；
- [ ] Scene2 的所有桥接定理均有完整 proof term；
- [ ] Scene2 的最终 `abc` 定理没有 `sorryAx`、未说明的数学参数或隐藏实例；
- [ ] 所有公共定理、导入图、来源登记和许可证登记均通过审计；
- [ ] 形式化明确区分已证明定理、条件性接口、Prologue 证明债务和研究阻塞项。

Act2 的开始不是“先搭一个 Completion 空目录”，而是上述门槛通过后的正式阶段转换。
