## S1.107：从 completion 赋值导出 IUT q-order

时间：2026-10-07 08:48 CST
当前行动：适配 `iut` 的 `TateParameter.toOrdered/orderNat` 局部归一化，将 base completion
上的 q-order 从整数赋值导出，并检查其与 chosen uniformizer 范数幂公式一致。

### 实际闭合程度

- 闭合：`iutCompletionQOrder w q := Int.toNat (-log (Valued.v q))`。从 `q ≠ 0` 和
  `‖q‖ < 1` 证明 q-order 为正；证明 `Valued.v q = exp (-qOrder)`；对任意满足
  `Arithmetic.IsCompletionUniformizer` 的 `π` 证明
  `‖q‖ = ‖π‖ ^ qOrder`。
- 闭合：`IutBaseQPilotSource.qOrder` 现在是 completion q-order 的派生定义，不再接收
  独立 q-order 数值或独立正性证明。`IutCompletionTateValuation` 只保存 chosen uniformizer
  及其证书；其 norm/order 方程由本地参数条件和赋值定理推出。
- 新增：source 现在显式要求 completion-valued Tate 参数满足 `‖q‖ < 1`，并保留
  `Nat.Coprime ell qOrder`。`ImportAudit` 检查新导出定义、正性、赋值律和 uniformizer 幂范数律。
- 退休：无消费者的 `IutBaseQPilotSource.ofOverVBad_badPlaces` 定义性投影引理。新的依赖
  coprimality 字段令该引理的展开等价检查超过 400,000 heartbeats；ImportAudit 改为直接检查
  构造器本身。carrier 构造器和 `badFinset_spec` 保留。
- 转入 Prologue：无。
- 从 Prologue 取出：无。没有修改 Prologue/Core、Prologue/Candidate 或
  `Prologue/Obligations`，动态边界保持 `Prologue-R3 → Prologue-R3`。

### 验证

- `FieldOrientationAudit`、`IutPlaceSource`、`IutTateValuation` 定向模块分别通过；Act1
  聚合入口和 `Prologue/Audit/ImportAudit.lean` 均通过。
- 所有 Lean 定向构建均设置 `ulimit -v 16777216` 与 `LEAN_NUM_THREADS=1`。本轮未用
  `/usr/bin/time -v` 测量峰值 RSS；虚拟内存地址空间限制保持 `16 GiB`。
- `ImportAudit` 中新增三个 `#print axioms` 检查；q-order valuation、uniformizer 幂范数律和
  `IutCompletionTateValuation.norm_eq_pow_order` 均只依赖 `propext`、`Classical.choice`、
  `Quot.sound`。
- 未运行全量构建。上次全量构建基线后成功推送计数为 `4/10`；本单元成功推送后计为
  `5/10`，下一次全量构建安排在 `10/10`。全量虚拟内存上限仍为 `60 GiB`。
- 本轮没有新增 `sorry`、自定义 `axiom` 或 `admit`；没有 Prologue 边界变更。

### 证明义务

- 尚未证明真实 `AdmissiblePrimeData.q_order_coprime` 与由本地 completion `Valued.v` 导出的
  q-order 是同一个整数。要闭合此项，仍需构造外部 Tate 参数、chosen uniformizer 与本地
  completion 元素之间的 source 等式。
- 尚未从真实 `InitialThetaData/TateFamily` 构造 base-field Tate 参数、q-pilot carrier、
  torsion-field q-root family 或 completion comparison map。
- 论文 `V_p^oss` 过滤的来源等式、raw 与 degree-normalized q-factor 的冻结选择、
  packet/hull 到 `thetaVolume` 的定量 accounting、完整 3.12 形式及真实非退化满足模型仍开放。
- 本单元只闭合条件性来源接口中的一个局部整数阶定理；不构造 q-root，不推出 q-pilot 总和或
  theta-volume 下界，也不关闭第二个形式冻结闸门。

## S1.108：将 IUT normalized q-order 对齐到 completion 阶

时间：2026-10-07 09:16 CST
当前行动：使用 IUT `TateParameter.toOrdered/orderNat` 的 chosen-uniformizer 范数幂律，证明其
整数阶等于 S1.107 定义的 completion valuation 阶，并把 `q_order_coprime` 传递到该派生阶。

### 实际闭合程度

- 闭合：`iutCompletionQOrder_eq_of_norm_eq_uniformizer_pow`。若 completion 参数 `q` 与已认证
  uniformizer `π` 满足 `‖q‖ = ‖π‖ ^ n`，则由 S1.107 得到的同一范数表达式以及
  `0 < ‖π‖ < 1` 下自然数幂单射，证明 `iutCompletionQOrder w q = n`。
- 闭合：`IutCompletionTateValuation.completionQOrder_eq_orderNat` 和
  `IutCompletionTateValuation.qOrder_coprime`。给定 IUT 形状的 `orderedQOrder`、它的
  范数幂律及 `Nat.Coprime ell orderedQOrder`，派生出本地 completion 阶的互素性。
- 新增：`IutCompletionTateValuation` 显式承载 IUT normalized order、其 admissible-prime
  互素证书及 chosen-uniformizer 范数幂律；ImportAudit 检查相等、互素传递及公理依赖。
- 退休：`IutBaseQPilotSource.qOrder_coprime` 和 `ofOverVBad` 中对应的局部互素实参。它们
  原先把 IUT 的条件直接写在本地派生阶上，却没有给出两种阶之间的来源等式。
- 转入 Prologue：无。
- 从 Prologue 取出：无。没有修改 Core、Candidate 或 `Prologue/Obligations`；边界保持
  `Prologue-R3 → Prologue-R3`。证明/信任负担变化：调用者不再重复提交“本地阶互素”；现在
  必须在 completion source 中提供 IUT 阶、IUT 互素证书和范数幂律，之后本地阶的等同及互素
  性由 proof term 推出。前置信任负担不变。

  Lake 报告 3723 jobs 成功，退出码 `0`。这是指定目标的定向构建，不是每十次推送安排的默认
  全量 `lake build`。

  `4,273,740 kB`，最高 VSZ 为 `8,751,028 kB`；这是采样值，不是精确峰值测量。
