# 构建与审计入口

所有命令从 `ArithmeticTeichmullerSpaces/` 运行。Lean 与 Mathlib 继续使用冻结版本。
默认 `lake build` 构建 Lean 库；模型审计和公理打印由显式模块目标开启。

| 用途 | 模块目标 | 行为 |
| --- | --- | --- |
| 日常冷热构建 | 不指定目标（默认 Lean 库） | 生产代码与 20 个生产 check 家族；不导入 Prologue.Audit，不打印公理 |
| 单家族名称检查 | `ArithmeticTeichmullerSpaces.Prologue.Audit.Checks.<Family>` | 只检查该家族；失败显示家族模块名 |
| 完整名称/模型审计 | `ArithmeticTeichmullerSpaces.Prologue.Audit` | 22 个 check 家族，包含模型与覆盖检查；不打印公理 |
| 只打印公理 | `ArithmeticTeichmullerSpaces.Prologue.Audit.AxiomAudit` | 19 个独立公理家族；不依赖 check 聚合入口 |
| 里程碑完整审计 | `ArithmeticTeichmullerSpaces.Audit` | 打开 Prologue.Audit 与 AxiomAudit 两个入口 |
| 单家族公理审计 | `ArithmeticTeichmullerSpaces.Prologue.Audit.Axioms.<Family>` | 只打印该家族公理 |

日常：

```sh
taskset -c 0-13 env LEAN_NUM_THREADS=10 lake build
```

仅检查修改家族，可以在同一次 Lake 构建中列出多个家族：

```sh
taskset -c 0-13 env LEAN_NUM_THREADS=10 lake build \
  ArithmeticTeichmullerSpaces.Prologue.Audit.Checks.Completion \
  ArithmeticTeichmullerSpaces.Prologue.Audit.Checks.Torsion
```

里程碑需要公理审计时：

```sh
taskset -c 0-13 env LEAN_NUM_THREADS=10 lake build ArithmeticTeichmullerSpaces.Audit
```

`LEAN_NUM_THREADS=10` 控制 Lake 调度池；库配置中的 `weakLeanArgs = ["-j1"]`
让每个 Lean 编译进程保持单线程，且不因线程参数改变而清空已有构建 trace。
冻结版本的 `-Kjobs` 是配置文件选项，本配置没有读取它，不能用它控制实际并行度。
使用一次 Lake 构建调度多个家族，避免多个 Lake 进程争用同一个 `.lake/build`。
运行时遵守 CPU 0–13 和 90 GiB 上限；没有 memory cgroup 时，以进程组 RSS 每
0.5 秒采样并在 85 GiB 停止，触及阈值后降低 Lake 调度池线程数。
